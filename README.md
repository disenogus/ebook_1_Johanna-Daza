# Sanando la desconexión emocional en pareja — E-Book (Johanna Daza)

Versión 1 · HTML · formato carta (8.5 × 11 in) · 32 páginas

- `index.html` → el E-Book completo (abrir en el navegador).
- `css/style.css`, `js/view.js`, `assets/` → diseño, tipografías (incluidas, funciona sin internet), imágenes y logos.
- `IMAGENES_PENDIENTES.md` → lista de imágenes de banco y fotos de Johanna por reemplazar.
- `build.py` → generador del HTML (contenido + maquetación). Ejecutar `python3 build.py` regenera `index.html`.

## Reemplazar un placeholder
Guardar la imagen con el nombre indicado en `assets/stock/` (banco) o `assets/client/` (fotos de Johanna). Se muestra sola.

## Versión final / PDF
- `index.html?final` oculta etiquetas de borrador y textos de placeholder.
- El PDF se genera al aprobar la última iteración (Chromium, tamaño carta, sin márgenes).
